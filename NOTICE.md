# Notices

Hestra AI is a hackathon project by CitraZhang Team from Ahmad Dahlan University.

## Data and API Providers

Hestra AI can connect to Sectors through a server-side API key. Sectors data, API access, branding, and any redistribution rights are governed by Sectors' own terms. Hestra's deterministic research signals are derived from Sectors-backed data and are not official Sectors-native fields.

Hestra AI can connect to SumoPod sandbox for payment flow testing. Sandbox payment states are for demonstration and development only.

## AI Providers

Hestra AI follows a Bring Your Own Key model for AI inference. Users can configure an OpenAI-compatible provider from Settings. AI model access, token billing, and model output terms are governed by the selected provider.

## Third-Party Software

This repository uses open-source dependencies from the Node.js and Python ecosystems, including Next.js, React, FastAPI, SQLAlchemy, Recharts, React Flow, Driver.js, Three.js, and Remotion. See each package's published license for exact terms.

Remotion has a special license for some commercial use cases. If this project is used beyond hackathon evaluation or internal demonstration, review Remotion's current licensing requirements before commercial deployment.

## Generated Media

Rendered videos, local recordings, voice-over files, and machine-local captures are treated as generated artifacts and are intentionally ignored by Git unless explicitly added for a release package.
